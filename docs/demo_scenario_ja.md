## 1. 作り込み内容の説明（5〜7分）

### 作り込みの全体構成

```
Google Spreadsheet
  ├── Config シート        ：APIキー・Network IDの管理
  ├── VLAN_Settings シート ：MX VLANの設定値
  ├── MS_Settings シート   ：MSトランクポートの設定値
  ├── SSID_Settings シート ：MR SSIDの設定値
  ├── RF_Settings シート   ：RF Profileの設定値
  └── Log シート           ：実行履歴の自動記録
```

### 実装した機能一覧

| 機能 | 内容 |
|------|------|
| 機能① | 設定の一括反映（MX → MS → MR → RF） |
| 機能② | 確認ダイアログ（全設定変更前に表示） |
| 機能③ | 差分チェック（設定反映後に自動比較） |
| 機能④ | ログの自動記録（実行日時・実行者・結果） |
| 機能⑤ | バックアップ（設定変更前に自動保存） |
| 機能⑥ | ロールバック（バックアップから復元） |

### ネットワーク構成

```
MX（ルーター）
  ├── VLAN 10：Corp-WiFi  （192.168.10.0/24）
  ├── VLAN 20：Guest-WiFi （192.168.20.0/24）
  └── VLAN 30：IoT-WiFi   （192.168.30.0/24）
        ↓ タギング
MS（スイッチ）
  └── Trunk Port（VLAN 10, 20, 30を通過）
        ↓ タギング
MR（アクセスポイント）
  ├── Corp-WiFi  → VLAN 10（WPA3 Personal）
  ├── Guest-WiFi → VLAN 20（WPA2 Personal）
  └── IoT-WiFi   → VLAN 30（WPA2 Enterprise）
```

## 2. 課題提起（3〜5分）

### 問いかけ例

- 現在、Merakiの初期設定はどのように行っていますか？
- 設定に時間がかかっていませんか？
- 設定ミスによる手戻りはありますか？
- 誰が・いつ・何を変更したか記録が残っていますか？
- 複数拠点に同じ設定を何度も手入力していませんか？

### よくある課題

| 課題 | 内容 |
|------|------|
| 課題① 設定に時間がかかる | SSIDを1つずつダッシュボードで手入力している |
| 課題② ヒューマンエラーが起きる | 設定値の打ち間違い・設定漏れが発生する |
| 課題③ 設定内容の記録が残らない | 誰が・いつ・何を変更したかがわからない |
| 課題④ 同じ作業を繰り返す | 複数拠点に同じ設定を何度も手入力している |

## 3. ソリューション説明（3〜5分）

### 3つのポイント

| ポイント | 内容 |
|---------|------|
| 簡単 | Excelライクな表に設定を入力するだけ。専門知識不要 |
| 正確 | ボタン1つで全設定が自動反映。設定後に自動で差分チェック |
| 安心 | 設定前に自動バックアップ。問題発生時はワンクリックでロールバック |

### 全体構成図

```
【管理者の操作】              【自動で行われること】
Google Spreadsheet            Meraki Dashboard
  設定値を入力      ──→      MX：VLAN設定反映
  ボタンをクリック  ──→      MS：トランク設定反映
                    ──→      MR：SSID設定反映
                    ──→      RF：Profile設定反映
                    ──→      差分チェック実施
                    ──→      ログ自動記録
```

## 4. デモ実施（10〜15分）

### Step 1：Spreadsheetの設定内容を確認する（約2分）

**見せるシート：**
- Config シート：APIキー・Network IDの設定場所
- VLAN_Settings シート：MX VLANの設定内容
- SSID_Settings シート：SSID名・認証方式・VLAN ID・IPモード

**話すポイント：**
- 「管理者はこの表に設定値を入力するだけです。」
- 「設定値はドロップダウンで選択できるので入力ミスが起きません。」

### Step 2：バックアップを取得する（約1〜2分）

```
🚀 Meraki 初期設定 → 💾 現在の設定をバックアップする → YES
```

**話すポイント：**
- 「設定変更前に必ずバックアップを取ります。」
- 「問題が起きた時はここから一瞬で復元できます。」

### Step 3：設定を一括反映する（約3〜5分）

```
🚀 Meraki 初期設定 → 🎉 全設定を一括反映する（MX→MS→MR→RF） → YES
```

**実行中に話すポイント：**
- Step 1：MXにVLAN 10・20・30を作成
- Step 2：MSのポートをTrunkに設定
- Step 3：MRにSSIDを設定
- Step 4：RF Profileを設定
- Step 5：各設定後に差分チェックを自動実施

### Step 4：結果を確認する（約3〜5分）

| 確認場所 | 確認内容 |
|---------|---------|
| 各シートのG列（ステータス） | ✅ 成功 が表示されている |
| 各シートのH列（差分確認） | ✅ 一致 が表示されている |
| Logシート | 実行日時・実行者・結果が記録されている |
| Merakiダッシュボード | 設定が正しく反映されている |

### Step 5：ロールバックを見せる（約2〜3分）

```
🚀 Meraki 初期設定 → ↩️ 設定をロールバックする → 番号を選択 → YES
```

**話すポイント：**
- 「万が一の時も設定を一瞬で元に戻せます。」

## 5. 使用APIエンドポイント（3〜5分）

Base URL：`https://api.meraki.com/api/v1`

| # | 用途 | メソッド | エンドポイント |
|---|------|---------|--------------|
| 1 | VLAN機能の有効化 | PUT | `/networks/{networkId}/appliance/vlans/settings` |
| 2 | VLAN一覧取得 | GET | `/networks/{networkId}/appliance/vlans` |
| 3 | VLAN新規作成 | POST | `/networks/{networkId}/appliance/vlans` |
| 4 | VLAN設定更新 | PUT | `/networks/{networkId}/appliance/vlans/{vlanId}` |
| 5 | デバイス一覧取得 | GET | `/networks/{networkId}/devices` |
| 6 | スイッチポート設定更新 | PUT | `/devices/{serial}/switch/ports/{portId}` |
| 7 | スイッチポート設定確認 | GET | `/devices/{serial}/switch/ports/{portId}` |
| 8 | SSID設定更新 | PUT | `/networks/{networkId}/wireless/ssids/{number}` |
| 9 | SSID設定確認 | GET | `/networks/{networkId}/wireless/ssids/{number}` |
| 10 | SSID一覧取得 | GET | `/networks/{networkId}/wireless/ssids` |
| 11 | RF Profile新規作成 | POST | `/networks/{networkId}/wireless/rfProfiles` |
| 12 | RF Profile確認 | GET | `/networks/{networkId}/wireless/rfProfiles/{rfProfileId}` |

## 6. 効果・まとめ（3〜5分）

### 工数比較

| 作業内容 | 従来（手動） | 自動化後 |
|---------|-----------|---------|
| SSID設定（3つ） | 約15〜20分 | 約1〜2分 |
| VLAN設定（3つ） | 約10〜15分 | 自動 |
| スイッチポート設定 | 約10〜15分 | 自動 |
| RF Profile設定 | 約5〜10分 | 自動 |
| 設定確認 | 手動目視 | 自動差分チェック |
| 変更履歴管理 | 手動記録 | 自動ログ記録 |
| 障害時の復旧 | 手動で再設定 | ワンクリック復元 |

### 3つの価値

| 価値 | 内容 |
|------|------|
| 時間の削減 | 設定作業を大幅に短縮。繰り返し作業をゼロに近づける |
| ミスの防止 | ドロップダウン入力で打ち間違いを防止。差分チェックで正確性を自動確認 |
| 運用の見える化 | 変更履歴が自動記録。誰が・いつ・何を変更したかが一目でわかる |

## 7. 質疑応答（5〜10分）

| 質問 | 回答例 |
|------|--------|
| セキュリティは大丈夫ですか？ | APIキーはConfigシートで管理しており、アクセス権限のある管理者のみ操作できます |
| 複数拠点には対応できますか？ | NetworksシートにNetwork IDを追加することで複数拠点への一括反映が可能です |
| 設定できる項目を増やせますか？ | Meraki APIが対応している設定であれば追加可能です |
| 既存の設定に影響しますか？ | 事前にバックアップを取得するため、既存設定への影響を最小限に抑えられます |
| 導入のハードルは高いですか？ | Google SpreadsheetとMeraki APIキーがあれば今日からでも始められます |
