# Meraki_Google-Spreadsheet_Dashboard-Setup_Sample
This project automates Meraki dashboard initial configuration using Google Apps Script and Google Sheets, enabling users to save time, minimize manual errors, and maintain reliable configuration backups through a simple interface.

While this spreadsheet includes placeholders for API keys in the 'Config' sheet, please ensure you store your actual credentials in a secure environment.
For example, you should configure your Meraki API key using the 'Script Properties' feature in the Google Apps Script editor to maintain security.

You can access and copy the sample Google Spreadsheet link provided below.
